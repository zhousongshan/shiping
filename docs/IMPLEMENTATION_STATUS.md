> 这是2026-09-27的历史快照，文中的发布状态和范围描述仅指当时。当前交接说明与最新需求请读根目录 [DEVELOPMENT_HANDOFF.md](../DEVELOPMENT_HANDOFF.md)。

日期：2026-09-27。代码位于本仓库，尚未发布到 GitHub 或公司服务器。

## 已实现

1. **结构化失败**：区分认证、限流、网络、超时、参数拒绝、未知提交等；未知收费请求不采用普通网络重试。修复 Harness 退出后末尾事件可能丢失的问题。
2. **持久数据库基础**：支持 PostgreSQL，保留本地 SQLite；事务保护日配额、请求去重、生成容量和提交意图。修复并发事件丢失及用户历史列表被其他用户任务挤掉的问题。
3. **独立执行服务**：API 可独立启动，Worker 使用数据库/本地领导锁防止多个调度器恢复同一批任务；内部并发执行。远端等待保存下次查询时间与40分钟等待起点，释放本地执行槽；重启不会重置等待超时。
4. **安全恢复**：理解和查询步骤的可重试故障有限自动恢复；手动继续、回答和回执恢复使用原子状态检查，旧请求不能把已运行任务重新排队。提交不明继续保留，不自动重发。
5. **账号与权限**：数据库账号存储 scrypt 摘要，员工/管理员角色，禁用、令牌更换、退出失效与登录限流；即使最后一个账号被禁用，也不会回退为匿名模式。提供账号管理 CLI、管理员状态接口和简单页面。
6. **部署与交付**：生产配置缺失时拒绝启动，独立 Worker 心跳与就绪检查；Docker Compose/HTTPS/持久数据卷模板，迁移和备份脚本、只读 doctor、依赖锁定、源码白名单导出。
7. **界面**：显示时长来自用户、参考或系统规划；网络重试保留同一提交编号与素材 ID；增加退出登录及管理员状态入口。

## 已完成的验证

- 最终完整测试：**90 项通过**，耗时约 22 秒；包含真实 PostgreSQL 事务测试。没有用模型假结果作为真实成片验收依据。
- 原有检查加新增并发提交、配额、未知回执保护、账号隔离、会话撤销、最后账号禁用、排队限制、有限等待、原子恢复等回归。
- PostgreSQL 迁移实测：1 个隔离任务与 1 个素材成功迁移，完整保留未知提交记录；重复迁移到非空数据库被拒绝。
- 独立进程实测：API 重启时 Worker 保持运行；Worker 停止后 `/api/ready` 返回 503，在线时返回 200。
- JS 语法、Python 编译与备份 shell 语法检查通过。
- 只读模型列表探测一次返回 HTTP 200，约 1.8 秒；这不是连接长期稳定或视频生成成功的证明。
- 源码压缩包白名单检查通过，不包含 data、API 密钥、素材、数据库、备份和本地依赖。

测试使用隔离临时目录与独立 PostgreSQL 验收数据库，未将用户历史任务迁移到新数据库，未创建新的收费视频生成任务。
