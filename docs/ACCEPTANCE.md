# 当前供应商真实验收清单

每条记录必须包含代码版本、供应商、输入素材哈希、用户、时长模式、最终计划、任务和远端 ID、耗时、预算占用、成片路径及人工结论。不得保存 API 密钥或公开签名 URL。

## 功能矩阵

| 输入 | 基础验收 | 当前结果 |
| --- | --- | --- |
| 文字 | 主体、场景、动作正确；跨段身份一致 | 待当前版本真实验收 |
| 图片 | 默认展示意图，保持身份 | 待当前版本真实验收 |
| 视频 | 保留主要事件、动作与节奏 | 待通道恢复和真实验收 |
| 文字＋图片 | 图中小鸡在户外跳舞；场景和动作来自文字 | 待真实成片验收 |
| 文字＋视频 | 明确修改与保留内容均实现 | 待真实验收 |
| 图片＋视频 | 完整替换主体，保留参考事件 | 待真实验收 |
| 三种输入 | 用户修改要求、目标主体和参考内容均满足 | 待真实验收 |

每种输入首轮至少 3 条样例，并增加自动、8/15/20/30/45/60 秒、严格/近似、180 秒参考边界、横竖/方形、有声/无声、多主体歧义与必要追问。长参考验证完整制作，不只验证上传成功。

## 故障与多人矩阵

重复点击与回执丢失不得盲目重新收费；断开理解模型应有限恢复；远端任务已存在时重启应继续查询；审片服务故障不能直接触发新视频生成；明确审核失败的返修要受预算约束。

多账号测试素材/任务/下载/候选/恢复权限，2/5/10 个账号同时提交不越权、不丢任务。实际执行并发遵守供应商容量，不等于同时发出 10 个生成请求。

## 统计

分别记录首次合格率、有限返修后合格率、无需管理员救场的交付率、按时长分组的 P50/P95、实际费用。报告样本数，不把单次成功当成长期稳定性。

验收预算未确定前不批量提交付费样例。72 小时观察和 Linux 部署验证尚未执行，禁止在交付报告中标为通过。
